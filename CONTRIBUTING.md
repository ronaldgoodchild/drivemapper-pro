# Contributing to DriveMapper Pro

Thanks for helping! This is a small, friendly project.

## Ways to help
- **Report a bug** - open an issue with your Windows version, what you clicked, and the last lines of `drive_events.log` (remove any server names or IPs first).
- **Suggest a feature** - open an issue or a Discussion.
- **Send a pull request** - fork, make a branch, keep the change focused, describe what you tested.
- **Improve the docs** - the guides in `docs/` are long and could use tidying.

## Dev setup
```powershell
pip install -r requirements.txt
python drivemapper_pro.py
```

## Ground rules
- Never include real credentials, IP addresses, share names or logs in issues or PRs.
- Be kind. See the Contributor Covenant (https://www.contributor-covenant.org/) - that is the standard we follow.
