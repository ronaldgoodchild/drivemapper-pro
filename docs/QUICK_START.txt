WELCOME!
This guide gets you up and running in 5 minutes.
For complete documentation, see DRIVEMAPPER_PRO_USER_MANUAL.txt

═══════════════════════════════════════════════════════════════
STEP 1: INSTALL REQUIREMENTS (First Time Only)
═══════════════════════════════════════════════════════════════

Open Command Prompt as Administrator and run:

    pip install customtkinter pywin32

Download rclone from https://rclone.org/downloads/
Extract rclone.exe to C:\Windows


═══════════════════════════════════════════════════════════════
STEP 2: LAUNCH DRIVEMAPPER PRO
═══════════════════════════════════════════════════════════════

Double-click: drivemapper_pro_v6.0_COMPLETE.py

OR open Command Prompt and run:
    python drivemapper_pro_v6.0_COMPLETE.py


═══════════════════════════════════════════════════════════════
STEP 3: MAP YOUR FIRST DRIVE (Drive Mapper Tab)
═══════════════════════════════════════════════════════════════

1. Select protocol (e.g., "SMB" for Windows shares)

2. Drive letter: Z (or any available letter)

3. Enter network path:
   • SMB: \\192.168.1.50\Media
   • Cloud: gdrive:Backup
   • SFTP: myserver.com

4. Enter username and password (if needed)

5. Click "✅ Validate & Add"

6. Click "▶ Map" to map the drive

7. Check File Explorer - your drive should appear!


═══════════════════════════════════════════════════════════════
STEP 4: CREATE A SYNC PROFILE (Sync Manager Tab)
═══════════════════════════════════════════════════════════════

1. Switch to "Sync Manager" tab

2. Enter profile name: "My Documents Backup"

3. Source: C:\Users\YourName\Documents

4. Destination: gdrive:Backup/Documents

5. Check "Bidirectional" for two-way sync
   OR leave unchecked for one-way backup

6. For first sync, check "Force resync"

7. Click "💾 Save Sync Profile"

8. Click "🔄 Sync Now" to run sync

9. Console window shows progress


═══════════════════════════════════════════════════════════════
IMPORTANT TIPS
═══════════════════════════════════════════════════════════════

ERROR 1219 (Multiple shares from same server):
• All shares from \\192.168.1.50 must use SAME credentials
• Click "🔧 Prepare" before "▶▶ Map All"
• Use "📋 Clone" to duplicate drive with same credentials

CLOUD STORAGE:
• Click "☁️ Rclone Config" to set up cloud remotes first
• Then use remotename: as path

WAKE-ON-LAN:
• Enter MAC address when adding drive
• Click "⚡ Wake" before mapping

TROUBLESHOOTING:
• Click "📜 Logs" to view detailed logs
• Click "🔍 Test" to diagnose drive detection
• See full manual for detailed solutions

COMMON SCENARIOS
═══════════════════════════════════════════════════════════════

SCENARIO 1: Map 4 shares from same server
────────────────────────────────────────────
Problem: Error 1219 when mapping multiple shares

Solution:
1. Add first share (Z: → \\server\share1) with credentials
2. Click "📋 Clone" on Z:
3. Change path to \share2, keep credentials
4. Repeat for remaining shares
5. Click "🔧 Prepare"
6. Click "▶▶ Map All"


SCENARIO 2: Backup to Google Drive
────────────────────────────────────────────
1. Click "☁️ Rclone Config"
2. Create "gdrive" remote (follow prompts)
3. Go to Sync Manager tab
4. Profile name: "Documents Backup"
5. Source: C:\Documents
6. Destination: gdrive:Backup
7. Uncheck bidirectional (one-way backup)
8. Check "Delete files on destination"
9. Check "Force resync"
10. Save and run sync


SCENARIO 3: Sync laptop and desktop via cloud
────────────────────────────────────────────
On both computers:
1. Create same cloud remote (e.g., "gdrive")
2. Profile name: "Work Files"
3. Source: C:\Work
4. Destination: gdrive:WorkSync
5. Check "Bidirectional"
6. Conflict resolution: "newer"
7. Save profile

Workflow:
• Laptop: Make changes, run sync
• Desktop: Run sync, get changes from laptop
